# TaskFlow - Personal Task Manager

## Description
**TaskFlow** is a modern web application for managing personal tasks and projects, built on Spring Boot using PostgreSQL and Docker 

## Technologies

| **Component** | **Technologies** | **Direction** |
|-----------|------------|------------|
| ***Backend*** | Java 17, Spring Boot 3.5.9 | Main framework |
| ***Database*** | PostgreSQL 15 | Data Storage |
| ***ORM*** | Spring Data JPA, Hibernate | Working with Database |
| ***API*** | REST, JSON | Interractions with Client |
| ***Container*** | Docker, Docker Compose | Isolation & Deployment |
| ***Build*** | Gradle | Building the project |
| ***Tools*** | Lombok, DevTools | Developing |
| ***Version Control*** | Git, GitHub | Code management |
